LOGIN COM GOOGLE — como ligar (grátis, uma vez só)
==================================================

O login usa o Firebase, que é do próprio Google e tem plano grátis.
Com ele, cada jogador entra com a conta Google e o progresso fica salvo na nuvem:
dá para continuar no celular, no PC ou em outro aparelho.

1) Entre em https://console.firebase.google.com com a sua conta Google.
2) "Criar projeto" > nome: reinos-de-eldmor > pode desligar o Google Analytics > Criar.
3) No menu da esquerda: Criação > Authentication > "Vamos começar".
   Em "Método de login", escolha Google > Ativar > escolha seu e-mail de suporte > Salvar.
4) Ainda em Authentication > Configurações > Domínios autorizados > "Adicionar domínio":
     tiuzinnnnnbr.github.io
     eldmor.onrender.com        (o endereço do seu servidor, se você tiver)
5) Menu da esquerda: Criação > Firestore Database > Criar banco de dados >
   local: southamerica-east1 (São Paulo) > "Iniciar no modo de produção" > Criar.
6) No Firestore, aba "Regras", apague tudo, cole isto e clique em Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /saves/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

7) Clique na engrenagem (Configurações do projeto) > em "Seus apps" clique no ícone </> (Web) >
   apelido: eldmor > Registrar app. Vai aparecer um bloco "const firebaseConfig = { ... }".
8) Abra o arquivo config.js do jogo e troque  window.ELD_FIREBASE = null;  por:
   window.ELD_FIREBASE = { ...o que estava dentro do firebaseConfig... };
9) Envie o config.js junto com o jogo para o GitHub (e para a pasta public do servidor).

Pronto: na tela inicial e no menu Online aparece "Entrar com Google".

IMPORTANTE
- Funciona no navegador: site do GitHub Pages, servidor e Safari do iPhone (pelo ícone na tela de início).
- No APK e no programa de PC o Google bloqueia login dentro de app. Quem quiser salvar na nuvem
  entra pelo site uma vez; o jogo continua salvando no aparelho normalmente.
- Essas chaves do config.js podem ficar públicas, isso é normal no Firebase. Quem protege os
  saves são as regras do passo 6 (cada um só lê e escreve o próprio progresso).
